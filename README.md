# Конструктор декора

Статический сайт для GitHub Pages. Никакого сервера не требуется.

## Что умеет

- Загружать собственную PNG-плашку вместо основы.
- Показывать декор поверх основы.
- Порядок слоёв:
  1. Общий план
  2. Ближняя ветка
  3. На коте
  4. Дальняя ветка
- Категории справа раскрываются/сворачиваются.
- В каждой категории список можно прокручивать.
- При выборе обычного декора другой элемент того же слоя заменяется.
- При выборе сета весь обычный декор снимается.
- У каждого декора есть название и цена.
- Итоговая цена автоматически считается в жемчужинах.
- Можно добавлять собственный PNG-декор прямо через интерфейс.
- Добавленный через интерфейс декор сохраняется в localStorage браузера.
- Можно скачать результат как PNG.

## Заглушки

В папке `assets` должны находиться:

- `плашка1.png`
- `плашка3.png`
- `плашка4.png`

Сейчас код использует их как демонстрационные изображения. Если эти файлы будут отсутствовать, сайт всё равно откроется, но соответствующие изображения не будут показаны.

## Как добавить постоянный декор

Откройте `decor.js` и добавьте объект:

```js
{ 
  id: "unique-id",
  name: "Название",
  price: 20,
  category: "near",
  src: "assets/my-decoration.png"
}
```

Категории:

- `far` — Дальняя ветка
- `near` — Ближняя ветка
- `cat` — На коте
- `plan` — Общий план
- `set` — Сеты

Для GitHub Pages достаточно загрузить все файлы репозитория и включить Pages из ветки `main`.

## Важный момент про PNG

Чтобы слои работали как задумано, декор лучше делать PNG с прозрачным фоном и одинаковым размером холста.

Например, если основа 1000×1000, каждый декоративный PNG тоже лучше сделать 1000×1000. Тогда при наложении координаты совпадут идеально.
